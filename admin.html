Esta página convierte el Excel de Cobertura Chile en el archivo datos/cobertura.js, cifrado con el código del equipo. El Excel no sale de tu computador: todo se procesa aquí, en el navegador.

1Código del equipo

Es el código que escriben los operadores para entrar. Usa al menos 8 caracteres, mezclando letras y números.

2Excel de cobertura

En Google Sheets: Archivo → Descargar → Microsoft Excel (.xlsx). También sirve un CSV. Columnas necesarias: LOCALIDAD, COMUNA, COURIER y TIEMPO DE ENTREGA.

3Revisión

4Generar y publicar

Se descargó cobertura.js. Ahora súbelo a GitHub:

  1. Abre el repositorio en GitHub y entra a la carpeta datos.
  2. Presiona Add file → Upload files y arrastra el cobertura.js descargado.
  3. Presiona Commit changes.
  4. En 1 a 2 minutos los operadores verán los datos nuevos al recargar la página.

Para probar en este computador: copia el archivo a la carpeta datos del proyecto y abre index.html.
